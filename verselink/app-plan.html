Overview

Purpose

The purpose of my website is to provide a modern scripture research tool that allows users to explore connections between scriptures, general conference talks, historical Church teachings, and their own personal study notes.

Audience

My intended audience is members of The Church of Jesus Christ of Latter-day Saints and anyone interested in studying the scriptures more deeply. The site will make scripture research easier and more organized by bringing relevant references and personal insights together in one place.

Dynamic elements

I will use JavaScript to make my website interactive and improve the user experience. JavaScript will allow users to navigate between scripture books and chapters, select individual verses, and open dynamic side panels displaying related general conference talks and historical references. Users will also be able to filter and search citations, expand or collapse sections, and switch between different sources without reloading the entire page. Additionally, JavaScript will help manage personal study notes and dynamically display journal entries connected to specific scriptures.

Color usage

Warm cream (#F3F0E8) is the page background. Deep navy (#263B53) is used for headings, body text, and the three main navigation options. Navigation labels are cream. Muted brown (#8B635C) frames the header and footer in the mockup and provides small decorative accents. Forest green (#38564A) is reserved for hover and selected states. Small text on the brown accent should be cream.

Typography

Headings: Libre Baskerville. Its traditional serif shapes complement the VerseLink wordmark and give the site a quiet, book-like character. Use regular weight for large headings and bold for smaller section headings. Georgia is the fallback font.

Body text and navigation: Lato. Use regular weight for paragraphs and large navigation labels, and bold for short labels that need emphasis. Keep body text at least 18px with a line height of 1.6 for comfortable reading. Helvetica and sans-serif are the fallback fonts.

Pseudocode for your project

Home page loads -> The user clicks on some type of scripture. -> It then goes to sub categories (if they picked Book of Mormon, the sub category is Alma) which are retrieved from an API and stored as objects. -> The user goes through any other sub categories to get to the scripture they're seeking. -> The user then can click on a verse and see other scriptures that reference it. -> My first goal is to start working on it with just one book of scripture.
